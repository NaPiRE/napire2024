Variance of Failing to Document

Julian Frattini

2026-04-09

This document analyses the variance of responses to the question “Have you ever failed to document one or more requirements?” (v_577) across demographic factors. The variable has the following levels:

Level Text
Yes Yes
No No
Not applicable I do not document requirements. 
v <- "v_577"
vname <- "failing to document"
labels <- c("Yes", "No", "Not applicable")
levels <- c("Yes", "No", "I do not document requirements")

# minimum likelihood of responses to be considered "common"
level.common <- 0.2

Variables

We consider the following demographic factors:

Code Name Question Type
v_23 country In which country are you personally located? categorical
v_3 size How many people are involved in your project? numeric
v_457 way of working How would you personally characterise the way your project works? ordinal
v_1 sector Please select the main industrial sector of your project or the application domain of the software you build. categorical
v_16 external Does your project involve external partners? binary
v_357 distributed Is your project distributed? binary
v_377 virtualization Do you tend to work from home, on-site, or both? ordinal
v_17 role What is the main role you occupy in your project? categorical

Data Analysis

We analyze the variance of the response variable following established practices of Bayesian data analysis.1

d <- load_data(run = "2024", data_path = "../../data", file = "runs/napire2024/data_cleaned_2024.csv") %>% 
  select("lfdn", # respondent identifier
    "v_3", "Country", "v_1", "v_457", "v_16", "v_357", "v_377", "v_17", # demographic factors
    v) %>%  # response variable
  drop_na() %>% 
  mutate(
    response = factor(!!sym(v), levels = levels, labels = labels, ordered = FALSE)
  )

For each outcome variable, we train one Bayesian regression model on all demographic variables as predictors.

Modelling

First, we define a formula regressing the outcome variable of interest on the demographic factors

f <- bf(response ~ 1 + v_3 + Country + v_1 + v_457 + v_16 + v_357 + v_377 + v_17)

#get_prior(f, data = d, family = categorical(link = logit))

For each coefficient implied by a predictor, we specify a prior based on domain knowledge.

p <- c(
  set_prior("normal(0, 1)", class = "Intercept", dpar = c("muNo", "muNotapplicable")), 
  set_prior("normal(0, 0.2)", class = "b", dpar = c("muNo", "muNotapplicable"))
)

Since the response variable is a categorical variable without any inherent ordering to it, we use a categorical model family to model it.

m.prior <-
  brm(data = d, family = categorical(link = logit), formula = f, prior = p,
    iter = 2000, warmup = 1000, chains = 4, cores = 4,
    seed = 4, sample_prior="only",
    file = paste0("../fits/variance.", v, ".prior"), file_refit = "on_change"
  )

brms::pp_check(m.prior, ndraws=100, type = "bars")

The prior predictive check confirms the plausibility of the selected prior probability distribution. Given the number of predictors, the weight towards the extreme values is anticipated. Next, we update the coefficient distributions in light of the collected data using Monte Carlo Markov Chain sampling.

m <-
  brm(data = d, family = categorical(link = logit), formula = f, prior = p,
    iter = 2000, warmup = 1000, chains = 4, cores = 4, seed = 4, 
    file = paste0("../fits/variance.", v), file_refit = "on_change"
  )

brms::pp_check(m, ndraws=100, type="bars")

The posterior predictive check shows that the model predictions (\(y_{rep}\)) have grown closer to the actually observed data (y). This confirms that the model has trained well.

Evaluation

We visualize the marginal effect of each demographic factor on every response option to determine, (1) whether an option can be viewed as “common”, and (2) whether the levels of the demographic factor affect the responses to this question. First, we investigate the effect of the sector (v_1) on all response options.

conditional_effects(m, "v_1", categorical = TRUE, prob = 0.95)[[1]] %>% 
  mutate(effect2__ = factor(effect2__, ordered = FALSE)) %>% 
  ggplot(aes(y = effect1__, color = effect2__)) +
    geom_point(aes(x = estimate__), position = position_dodge(width = 0.8)) + 
    geom_errorbar(aes(xmin = lower__, xmax = upper__), position = position_dodge(width = 0.8)) +
    geom_vline(xintercept = level.common, color = "grey", linetype = "dashed") +
    scale_x_continuous(labels = scales::percent) +
    labs(x = "Likelihood of selecting the option", y = "Sector", color = "Options") +
    ggtitle(paste0("Sector affecting ", vname)) +
    theme_bw()
